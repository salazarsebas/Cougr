# Cougr Voice and Style Guide

This guide establishes enforceability rules for technical documentation and public repository copy across Cougr.

## Voice Rules

1. **Precision First**: Write clear, direct declarative sentences. Avoid marketing fluff or non-technical jargon.
2. **Terminology Enforcement**:
   - Always refer to on-chain Soroban modules as **"contract"** (never "smart contract" after initial introductory mention).
   - Use **"component"** and **"system"** strictly in accordance with standard ECS conventions.
   - Use **"entity"** rather than "object" or "instance".
3. **Maturity Model Vocabulary**: Use `Stable`, `Beta`, and `Experimental` tags consistently across all module headers.
