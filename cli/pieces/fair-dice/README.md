# Fair Dice Piece

This project includes a ZK fair dice verifier generated by `cougr add fair-dice`.

## ⚠️ Trusted Setup Warning

The zero-knowledge circuits used by this piece (`cougr_core::circuits::fair_dice`) currently ship with **TEST-ONLY proving keys**. 

These keys were generated without a secure multi-party computation ceremony, meaning the setup secrets are known. **Do not use these keys in a production game or on mainnet.** Any player with access to the setup secrets could forge valid proofs for invalid dice rolls.

Before launching a production game, you must run or join a secure trusted setup ceremony to generate production proving keys for this circuit.
